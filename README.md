# Daily Life Skills

Personal Codex skills for everyday admin, writing, inbox cleanup, planning, and household workflows.

## Skills

- `application-answer-polisher`: Polish English written application answers into natural, specific, non-AI-sounding prose while preserving the user's story and voice.
- `conversation-writing-style`: Write Chinese long-form plain-text replies that feel natural, Word-ready, and less AI-formatted. Related writing rules live inside the same folder.
- `email-inbox-cleanup`: Review an email inbox, identify low-risk bulk cleanup candidates, ask for confirmation, and move confirmed matches to trash.
- `feishu-table-filter`: Restore personal Feishu/Lark table filters from a local, untracked configuration file before the user reviews records.
- `research-why-bank-program`: Research and draft differentiated, evidence-backed “Why this bank/company?” and “Why this programme/role?” answers.

## Repository Layout

Each skill lives in its own folder. A folder should contain the skill's `SKILL.md` plus any related examples, templates, local configuration examples, or reference documents.

- `application-answer-polisher/`: English application-answer polishing guidance and agent configuration.
- `conversation-writing-style/`: Chinese prose style rules and the full writing-style reference document.
- `email-inbox-cleanup/`: Email cleanup workflow and agent configuration.
- `feishu-table-filter/`: Feishu/Lark table filtering workflow, agent configuration, and local filter example.
- `research-why-bank-program/`: Employer and programme research workflow, agent configuration, and icon.
